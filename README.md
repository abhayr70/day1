# Personal Expense Tracker

A Java project built step-by-step as a daily GitHub project.

## Day 1
- Created the Java project structure
- Added the main Java class
- Added the initial application startup message

## Run

```bash
javac -d out src/main/java/com/expense/Main.java
java -cp out com.expense.Main
```

## GitHub

```bash
git init
git add .
git commit -m "Initial project setup"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```
